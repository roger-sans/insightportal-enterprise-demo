# InsightPortal v1.0.0 demo

The first demo ships a cross-domain analytics catalog, executive and domain dashboards, eight versioned KPIs, regional and monthly drill-down, source quality and freshness, analytics intake with independent review, and adoption tracking.

The local release uses deterministic synthetic aggregate data and persistent SQLite workflows. Acceptance evidence consists of the API suite, Chromium browser workflows and the synthetic stakeholder walkthrough. The optional Snowflake adapter and parity procedure are included for verification in a dedicated account.

Known follow-up work includes a bookings-to-revenue bridge, workforce disclosure review for a real pilot, Snowflake account-side verification and operational monitoring. This release is intended for a localhost portfolio demonstration.
